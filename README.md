# Task App

TornadoとSQLiteを使ったシンプルなタスク管理Webアプリです。

## 主な機能

- タスク登録
- 一覧表示
- 編集
- 削除
- 完了 / 未完了切替
- 並び替え
- 空欄入力チェック
- 効果音
